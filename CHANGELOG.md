# Changelog

## 1.0.0 — 2026-10-08

First method, specification, and visual template release of Living Project Atlas.

- Define an operational visual project workspace for a human Director.
- Begin with project preparation and joint concept development; require explicit Director approval of the conceptual baseline before building the atlas.
- Make the atlas the primary interface for execution and iteration after bootstrap.
- Specify proposal approval, steering, work controls, verification, and result review.
- Define durable commands, real execution adapters, version-bound authorization, and recovery.
- Connect project knowledge, operational state, evidence, and accepted changes.
- Provide implementation instructions, record templates, and end-to-end acceptance scenarios.
- Include a complete illustrative iteration through the web interface.
- Supply an original, dependency-free visual template inspired by the structure of Excavator: the Project Atlas.
- Include a responsive contents rail, project cover, map, topic chapters, decision desk, work board, review desk, concept baseline, search, and history.
- Demonstrate local approval, requests for changes, sample result acceptance, direction, and unacknowledged execution-control requests.
- Allow recorded decisions to be changed or reopened, with required rationale, preserved prior outcomes, revision checks, and changelog access.
- Require implementing agents to autonomously build contextual Director nudges for tasks and decisions, backed by a maintained runner, durable dispatch, and real execution feedback.
- Specify activation behavior for analysis, approved work, active jobs, changed decisions, pauses, offline recovery, and retries; require real execution demonstrations before operational handover.
- Document how the approved target concept replaces the example and how the frontend connects to a real operational service.

Release status: specification, implementation brief, and runnable frontend template. An operational backend and real execution connection are not included.
